# 1.4 Guía y Rúbrica: Pre-entrega 1 (Unified Async Client)

## 🎯 Qué Construir
Un repositorio de GitHub con una arquitectura limpia en Python 3.12 que contenga la implementación de un **"Unified Async LLM Client"**.

---

## 📊 Rúbrica Oficial de Evaluación (Total: 100 pts | Aprobación: 70 pts)

| Criterio | Peso | Requisitos Clave para Máximo Puntaje |
| :--- | :---: | :--- |
| **Abstracción y Gestión de Proveedores (`AsyncLLMManager`)** | **35%** | • Clase base abstracta `BaseLLMClient` con `generate()` y `generate_stream()`.<br>• Factoría `AsyncLLMManager` que instancie OpenAI y Anthropic dinámicamente según configuración sin modificar código de negocio. |
| **Implementación de Streaming Asíncrono** | **25%** | • Uso de generadores asíncronos (`yield` dentro de bucle `async for`).<br>• Entrega de tokens en tiempo real sin bloquear el Event Loop. |
| **Validación de Esquemas con Pydantic** | **20%** | • Modelos para `ChatMessage`, `LLMConfig`, `ModelResponse`.<br>• Rangos estrictos (`temperature` de 0 a 2, `max_tokens > 0`).<br>• Protección de credenciales con `SecretStr`. |
| **Resiliencia y Manejo de Errores** | **20%** | • Captura de fallos de red (`APIConnectionError`) y límites de cuota (`RateLimitError`).<br>• Respuesta estructurada con `error: Optional[str]` sin causar un crash general del sistema. |
