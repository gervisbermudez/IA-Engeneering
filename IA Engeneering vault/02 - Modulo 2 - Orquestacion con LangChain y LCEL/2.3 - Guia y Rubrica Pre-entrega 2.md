# 2.3 Guía y Rúbrica: Pre-entrega 2 (Pipeline Validado)

## 🎯 Qué Construir
Un **Pipeline de Extracción de Entidades Técnicas** con LangChain (LCEL) y Pydantic. El sistema debe recibir un párrafo de texto sin procesar (ej. descripción de arquitectura o log de error) y devolver un objeto Pydantic validado con manejo de reintentos.

---

## 📊 Rúbrica de Evaluación (Total: 100 pts | Aprobación: 70 pts)

| Criterio | Peso | Requisitos Clave |
| :--- | :---: | :--- |
| **Definición del Esquema y Salida Estructurada** | **30%** | • Modelo Pydantic con `tecnologias` (lista de strings), `nivel_de_criticidad` (enum: baja, media, alta) y `resumen_tecnico` (string).<br>• Uso de `with_structured_output()`. |
| **Implementación de Cadena LCEL y Prompting** | **30%** | • Composición modular con pipe (`|`): `prompt | model.with_structured_output(...)`.<br>• `ChatPromptTemplate` con instrucciones claras de extracción. |
| **Ejecución Asíncrona y Resiliencia** | **25%** | • Función `async def process_text(text: str)` ejecutada con `.ainvoke()`.<br>• Lógica de reintento (`.with_retry()`).<br>• Logs para observar el proceso de validación. |
| **Estructura del Repositorio y Script de Prueba** | **15%** | • Modularidad en `schemas.py`, `chain.py` y script de prueba.<br>• `README.md` con ejemplos de ejecución. |
