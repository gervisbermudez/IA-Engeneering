# 3.3 ChromaDB Local y Operaciones CRUD

## 🎯 Objetivo de la Unidad
Implementar persistencia vectorial local en disco utilizando ChromaDB, gestionando el ciclo de vida completo de los datos mediante operaciones de creación, consulta semántica, actualización y borrado (CRUD).

---

## 1. ¿Por qué ChromaDB para Desarrollo Local?

* **Cero dependencias de infraestructura**: No requiere contenedores Docker ni servicios en la nube para empezar.
* **Persistencia en disco**: Almacena colecciones en formato SQLite y Apache Parquet en una carpeta local (ej. `./vectorstore`), sobreviviendo a los reinicios de la aplicación.
* **Ideal para testing y prototipado**: Permite iterar pipelines RAG sin costo alguno de base de datos.

---

## 2. Operaciones CRUD en el Espacio Vectorial

```python
import chromadb
from chromadb.utils import embedding_functions

# Inicializar cliente persistente en disco
client = chromadb.PersistentClient(path="./vectorstore")

# Configurar función de embedding (o usar la default)
collection = client.get_or_create_collection(
    name="documentos_tecnicos",
    metadata={"hnsw:space": "cosine"}  # Métrica de similitud
)

# 1. CREATE / UPSERT (Insertar o actualizar)
collection.upsert(
    ids=["doc_1", "doc_2"],
    documents=[
        "FastAPI es un framework web asíncrono de alto rendimiento para Python.",
        "ChromaDB es una base de datos vectorial para persistir embeddings localmente."
    ],
    metadatas=[
        {"categoria": "backend", "fuente": "docs/fastapi.md"},
        {"categoria": "database", "fuente": "docs/chroma.md"}
    ]
)

# 2. READ: Query Semántico (Búsqueda por similitud)
resultados = collection.query(
    query_texts=["¿Cómo construir APIs veloces en Python?"],
    n_results=1,
    where={"categoria": "backend"}  # Filtrado de metadatos previo
)
print("Recuperado:", resultados["documents"][0][0])

# 3. UPDATE: Modificar metadatos o texto
collection.update(
    ids=["doc_1"],
    metadatas=[{"categoria": "backend", "fuente": "docs/fastapi_v2.md"}]
)

# 4. DELETE: Eliminar vectores obsoletos
collection.delete(ids=["doc_2"])
```

## 3. El Rol de los Metadatos y IDs Deterministas

> [!IMPORTANT]
> **IDs Deterministas vs Aleatorios**:
> Nunca utilices IDs puramente aleatorios (`uuid4()`) si necesitas reindexar documentos. Si el documento `politica_2026.pdf` se vuelve a procesar con un nuevo UUID, duplicarás todos sus vectores en la base.
> Usa hashes del contenido (`sha256(chunk_text)`) o identificadores estructurados (`doc_name_chunk_01`).
